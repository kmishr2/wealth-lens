# Calculation Principles

## Core Philosophy

All calculations must be:

- transparent
- deterministic
- explainable
- reproducible
- testable

---

# Deterministic Rule System

The application uses:

- formulas
- threshold rules
- benchmark comparisons
- explicit scoring systems

The application does NOT use:

- AI
- machine learning
- predictive systems
- probabilistic models

---

# Explainability Standards

Every calculation must expose:

- inputs
- formula
- assumptions
- interpretation

Example:

```txt
Equity Allocation =
(Total Equity Value / Total Portfolio Value) × 100
```

---

# Risk Calculation Principles

Risk metrics are historical and mathematical.

They are NOT predictive.

Example metrics:

- volatility
- drawdown
- beta
- concentration risk

---

# Health Score Principles

Health score must:

- be formula-driven
- expose scoring weights
- expose scoring categories
- remain deterministic

No hidden scoring logic allowed.

---

# Rebalancing Principles

Rebalancing suggestions are based only on:

- target allocation
- current allocation
- percentage drift

No advisory recommendations allowed.

---

# Projection Principles

Scenario analysis uses:

- explicit return assumptions
- deterministic compounding
- user-provided parameters

Future projections are simulations, not predictions.
